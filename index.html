Portfolio

Here are some of the projects I have worked on:

Ping-Pong

A 2D Ping Pong game developed using Snap!, featuring real-time paddle movement, collision detection, and ball physics. Players control paddles to keep the ball in play, and the game ends when the ball crosses a boundary.

SpellCheck++

A C++ spell checker implementing a custom hash table with double hashing and dynamic resizing. It detects common spelling errors and suggests corrections through a simple command-line interface.

Self-Balancing AVL Tree (C++)

This project implements a fully functional self-balancing AVL Tree in C++, supporting insertion, deletion, and search operations with guaranteed logarithmic time complexity. The code includes deep copy support, value/key traversal, and tree balancing via left/right rotations. A comprehensive test suite demonstrates correctness, edge cases, and memory safety.

RouteRadar

RouteRadar is a AI powered smart travel assistant designed to streamline campus or city navigation by integrating routing logic with services like Uber's API. The app intelligently determines optimal paths, estimates trip durations, and connects users to ride-hailing options. Ideal for students or commuters, RouteRadar emphasizes clean design and real-time routing capability.

FitPalette

FitPalette is a web application designed to help users get objective feedback on their outfits based on color harmony and coordination. Users upload individual images of their outfit items—upperwear, lowerwear, footwear, and accessories—and receive a visual score based on aesthetic principles like complementary colors, contrast, and overall palette cohesion.
