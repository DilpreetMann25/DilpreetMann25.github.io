# 🧑‍💻 Dilpreet Mann's Portfolio Website

Welcome to my personal portfolio website repository! This project showcases my development skills, personal projects, and professional experience as a Computing Science student at Simon Fraser University. It’s built with clean HTML, CSS, and JavaScript, and is fully responsive for both desktop and mobile users.

---

## 📁 Repository Structure

Here's an overview of the key files and folders included in this repository:

- **`index.html`**  
  The main HTML file that serves as the homepage and entry point to the website. It defines the structure, layout, and all major sections (Home, About, Portfolio, Skills).

- **`style.css`**  
  Contains the custom styles used to make the portfolio visually engaging and modern, including animations and dark theme.

- **`script.js`**  
  Adds smooth scroll functionality and other small interactive behaviors to enhance UX.

- **`images/`**  
  Stores all static image assets used throughout the website, including:
  - Project screenshots
  - Profile photos
  - Favicon files (`.png` and `.ico`)
  - Logos (e.g. LeetCode)

- **`ResumeP.pdf`**  
  My resume is included in the repository for quick viewing and download via the "View Resume" button.
